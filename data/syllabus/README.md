# Syllabus Data

This directory contains course syllabus source data.

Each subject should have a stable subject/course identity.

The actual content must be extracted from the supplied authoritative course source.

Do not invent missing syllabus items.

Recommended logical structure:

```text
course
 └── weeks
      └── items
```

Each syllabus item should have a stable source identity such as:

```text
L1.1
AQ1.1
PA1
GA1
```

Use the actual identifiers present in the source material.
